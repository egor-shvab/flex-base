# План: мобильная версия

Рабочий план улучшений для экранов уже 640px (`below-compact`) и 900px (`below-shell`). Основа —
осмотр всех страниц на ширине 375px. Этапы идут по порядку; каждый этап — одно отдельное изменение
со своим коммитом. Когда все этапы закрыты, файл удаляется (§12: история не хранится в документах).

**Каждый этап закрывается по definition of done из `CLAUDE.md` §2**, включая `reviewer`, проверку в
запущенном приложении на 375×812 и `npm run test:e2e` (меняется раскладка оболочки и записей). Ниже
у каждого этапа — только то, что сверх этого.

## Принятые решения

| Вопрос                                     | Решение                                                                                                         |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Строки таблицы записей на телефоне         | Остаётся таблица; на мобиле три иконки сворачиваются в одно `⋯`, номер записи становится ссылкой на её карточку |
| Место над строками на странице таблицы     | Компактная шапка; блокировка вьюпорта (`decisions.md` → _The viewport lock lives in the shell_) остаётся        |
| Увеличение тач-целей под `pointer: coarse` | Не делаем — `limitations.md` → _36px targets are below the Apple HIG…_ остаётся Accepted                        |
| Порядок разделов в настройках таблицы      | Поля выше доступов, на любой ширине; макет `Table Settings.dc.html` обновляется                                 |
| Строки полей в настройках таблицы          | На мобиле Edit и Delete сворачиваются в одно `⋯` в той же строке; e2e-тест о «стопке» переписывается            |

## Этап 1. Баги

**Готово.**

- 1.1 Вылет строки списка: в `BaseListRow` отступ `__trailing` теперь `padding`, а не `margin`;
  «Owner» в Members выровнен с селектами. E2e проверяет вылет на панели `main` (поля и Members).
- 1.2 Зум iOS: токен `--font-size-control` (14px, 16px под `pointer: coarse` — по указателю, а не по
  ширине: телефон боком шире любого брейкпоинта) читают `form-control` и значение `BaseSelect`.
- 1.3 Safe area: `viewport-fit=cover`; инсеты у топбара, `main`, бокового меню, `BaseCenteredPanel`
  и шторки.

## Этап 2. Таблица записей

**Готово.**

- 2.1 Ниже `below-compact` View и Edit строки уходят в `RecordRowMenu`; выше меню держит только
  Delete. `useMenuNavigation` пропускает пункты с `display: none`.
- 2.2 `#N` — ссылка на карточку на любой ширине; иконка View на десктопе остаётся (как в макете).
- 2.3 «Edit record» в подвале `RecordDetailModal` для записи своей таблицы при праве на правку.
- 2.4 `BasePageHead` ниже `below-compact` — одна строка: шаг назад иконкой, заголовок, действия;
  кнопки шапки с иконкой — `iconOnlyBelowCompact`. Mixin `visually-hidden`.
- 2.5 Секция Sort в шторке фильтров — только ниже `below-compact` (в макете её нет); пишет тот же
  `sort` в URL через `setSort`.

## Этап 3. Настройки

### 3.1 Вкладки настроек обрезаются

Вкладки General / Members / Roles / Danger (`settings.vue`, `overflow-x: auto`) не влезают:
«Danger» обрезан, под ними толстая полоса прокрутки.

- Спрятать скроллбар (`scrollbar-width: none` + `::-webkit-scrollbar`), добавить затухание к краю,
  с которого есть продолжение (маска, а не наложенный блок).
- Активная вкладка прокручивается в видимую область при загрузке (`scrollIntoView({ inline: 'nearest' })`).
- Альтернатива, если всё равно тесно: на мобиле только иконки + видимая подпись у активной. Решить
  по факту, проверив на 320px.

### 3.2 Строки полей: одно `⋯` в строке

Ниже `below-shell` Edit и Delete поля сворачиваются в одно `⋯`-меню («Edit field …»,
«Delete field …» — имена как у нынешних кнопок) в той же строке; `__trailing` больше не
переносится на новую строку для этого списка.

- Если меню нужно и строкам Members/Roles — сделать это возможностью `BaseListRow`
  (слот/проп), а не копией разметки.
- **Тест:** _a field row stacks its actions…_ переписать: действие в той же строке, имя не
  обрезано до нуля, панель без горизонтального вылета.

### 3.3 Поля выше доступов

На странице настроек таблицы раздел Fields идёт сразу после Table, Access — после Fields. Кнопка
«Add field» оказывается рядом со списком полей (в шапке раздела, а не страницы — решить по макету).

- Обновить макет `docs/design/Table Settings.dc.html` в том же изменении.

### 3.4 Панель сохранения роли

`BaseSaveBar` в редакторе роли и доступах таблицы всегда занимает ~60px, даже с «No unsaved
changes», и не имеет фона — контент просвечивает.

- Дать панели фон поверхности и верхнюю границу (`--color-border`), как у закреплённого подвала.
- Ниже `below-compact` в чистом состоянии панель сворачивается до тонкой строки статуса или
  скрывается; `role="status"` при этом сохраняется (статус «Saved» должен объявляться).

### 3.5 Кнопки General

«Save changes» и «Discard» на General видны и активны без изменений. Проверить поведение `useForm`:
если сохранение без изменений ничего не делает — кнопки неактивны (или Discard скрыт), пока форма
чистая. Не мобильная проблема, но найдена здесь.

## Этап 4. Полировка

### 4.1 Hover только для мыши

После тапа `:hover` залипает (строки таблицы и списков остаются подсвеченными). Добавить mixin
`hover` (`@media (hover: hover) { &:hover { … } }`) в `_mixins.scss` и перевести на него все
`&:hover` (~16 файлов). Строке таблицы с pinned-колонкой — оба правила (`tbody tr:hover` и ячейку
действий) вместе.

- `styling.md` — одна строка: hover-стили только через mixin.

### 4.2 Кнопка закрытия бокового меню

Сейчас меню закрывается только тапом по затемнению или Escape. Добавить кнопку «Hide tables»
(`icon`-вариант, иконка `close`) в шапку открытого меню ниже `below-shell`; фокус после закрытия
возвращается на кнопку-гамбургер (как уже при закрытии по Escape).

- **Тест:** кейс в `mobile-shell.spec.ts`.

### 4.3 Страница Invitations

- Нет пути назад: добавить крошки «Home» (как на настройках), если у пользователя есть воркспейс.
- Пустое состояние — `BaseEmptyState` вместо голого текста, как на остальных страницах.
- Ссылка на Invitations из меню — проверить, где она доступна на мобиле.

### 4.4 Вход и регистрация

`BaseCenteredPanel` центрирует форму по вертикали: на телефоне над ней половина экрана пустоты, а при
открытой клавиатуре форма прыгает. Ниже `below-compact` — выравнивание по верху с умеренным
отступом. Касается и страницы ошибки (тот же компонент) — проверить её.

## Вне плана

- Карточный вид записей вместо таблицы — отклонено в пользу таблицы с одним `⋯`.
- Прокрутка страницы целиком вместо блокировки вьюпорта — отклонено.
- Тач-цели 44px под `pointer: coarse` — остаётся Accepted в `limitations.md`.
